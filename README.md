# django-app
IDEA: A web-based forum-like app so that people can communicate with each other.

1.People can utilize guest accouts in which they can set their own username.
2.Search engine that will scan for any topic you search for if it exists.
3.Profile pictures can be used. An upvote system that will allow others to see the most popular post.
4.A calendar for important events.
5.Notifications can be turned on for events.
6.A map for the school.
7.A board with announcements everyone can see.
8.Badges or reputation point system for active users.
9.UI settings like scale, font, and dark/light mode.
