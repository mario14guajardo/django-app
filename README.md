# django-app
## Project Description
We will build a "web-based forum-like application" using Django that allows people to communicate, share announcements, and engage with their community. Users can post topics, reply to others, and interact through an upvote system. The app also includes community tools like events, maps, and customizable UI settings.

**Key Features:**
1. **Guest Accounts** - Users can participate without full registration and set a temporary username.
2. **Search Engine** - Find existing topics or discussions instantly.
3. **Profile Pictures** - Add and manage personal avatars.
4. **Upvote System** - Highlight popular posts and discussions.
5. **Calendar** - Display upcoming community or school events.
6. **Notifications** - Optional alerts for new events or updates.
7. **School Map** - View a map for easy navigation.
8. **Announcement Board** - Public bulleting visible to all users.
9. **Badges/Reputation System** - Reward active community members.
10. **UI Settings** - Customize theme (dark/light mode), font size, and layout scale.

**Goal:**
To create an interactive community platform that promotes communication and collaboration within a school or campus environment.
